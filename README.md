# Euler — Wobbling Coin & Spinning Disk Lab (GitHub Pages edition)

An interactive rigid-body physics & acoustics lab exploring the wobbling motion of a coin / Euler's disk, built for the Physics Playground series and IBDP Physics Internal Assessment (IA) investigations.

## Files
- index.html — page layout, pre-rendered KaTeX equations, and IA trial table
- style.css — responsive dark-brass observatory theme
- presets.js — specimen and surface presets
- model.js — adaptive RK4 solver, energy partition, and log-log regression
- audio.js — real-time Web Audio rolling-contact chirp synthesizer
- rendering.js — 3D projected disk stage and scientific plots
- app.js — controls, pointer drag, and CSV data exporter
- vendor/katex — bundled WOFF2 math fonts (offline-ready)
